# 项目：校园资讯动态发布网站（信息工程系官网）

- **开发周期**：2026年5月 – 2026年7月
- **担任角色**：全栈开发（独立完成）
- **技术栈**：PHP + MySQL + HTML5 + CSS3 + Bootstrap 5 + JavaScript + Summernote 富文本编辑器

## 项目描述
基于 PHP 和 MySQL 开发的校园信息门户，包含前台用户浏览端和后台管理端。  
前台支持新闻分类浏览、公告展示、用户登录/注册、匿名/实名留言、关键词搜索等功能；  
后台实现管理员权限验证、轮播图与新闻资讯的增删改查、公告置顶、留言审核与回复、二级菜单动态配置、用户管理及站点 Logo/名称设置。  
项目采用数据库存储图片（LONGBLOB），通过 `image.php` 接口输出，有效避免文件系统权限问题。

## 个人职责与核心贡献
- **数据库设计**：设计 11 张核心数据表（用户、新闻、公告、留言、菜单、图片等），合理设置主外键与索引，使用 utf8 字符集。
- **后台管理**：实现仪表盘统计、所有 CRUD 操作，全部使用预处理语句防 SQL 注入。
- **前台功能**：新闻列表分页与分类联动筛选、留言审核展示、用户注册登录会话管理、站内搜索，Bootstrap 响应式布局。
- **图片存储方案**：因共享服务器权限问题，改用二进制存入 MySQL + `image.php` 动态输出，配合 `finfo` 检测 MIME。
- **富文本集成**：Summernote 编辑器内图片上传至数据库，返回图片 URL 供渲染。
- **留言优化**：审核机制（默认不通过），一键通过/删除，内联回复表单。
- **动态菜单**：后台增删二级菜单，挂接独立内容，前端导航自动同步。

## 技术难点与解决
- 变量作用域：`$conn` 未定义 -> 使用 `global` 或封装 `db()` 辅助函数。
- 分类筛选与分页冲突 -> URL 同时携带 `category` 和 `page`，SQL 动态拼接条件。
- 侧边栏高度问题 -> `min-height: 100vh` + Flex 布局。
- 图片上传空警告 -> 增加 `UPLOAD_ERR_OK` 校验。
- Summernote 图片 404 -> 自定义接口返回图片 ID 路径，与 `image.php` 配合闭环。
